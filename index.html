MOBILE APPLICATION

Health & Hygiene App

I developed an Android-focused Health & Hygiene app with Flutter, bringing helpful everyday features together in one place. It includes daily water-intake tracking, medicine reminders, hygiene tips and health monitoring. I focused on making the interface clear and easy to use, and worked with local/Firebase database storage to manage user health records.

Development of an HTTP Server

For this project, I built a custom HTTP server in Python that handles client requests and serves web pages. I implemented GET and POST methods, explored routing and request handling, and connected the server to a responsive front end made with HTML, CSS and JavaScript.
